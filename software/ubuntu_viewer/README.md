# Ubuntu 清晰显示与报告界面

启动工具包根目录 `launch_ubuntu_example.py`，或桌面的「UMI-示例」快捷方式。

2026-09-22 修复：

- 使用本机 Ubuntu Tk + Xft，替代原 Conda Tk 的位图字体。默认采用 Noto Sans CJK SC，提供 100%–175% 字号选项。
- 运行中显示数据准备/SLAM 帧数；完成后显示绿色完成状态、有效位姿、总帧数、覆盖率和分段数。
- 完成后自动显示三个正交投影，保留 segment_id 断段；“查看轨迹报告”直接打开内置报告窗口，无需依赖浏览器。
- HTML 仍可通过单独按钮交给系统打开，增加失败提示。
- 重启时载入最近一次带质量报告的任务，已有结果无需重算。

原 `software/umi_slam` 中的算法、Docker 入口及历史 GUI 文件没有修改，历史校验清单保持有效。这个目录继承其启动/停止计算逻辑，仅更新 Ubuntu 前端。

本工作站使用 Ubuntu 22.04 / Python 3.10。`.runtime/ubuntu-tk` 中是经 APT 提供的 SHA512 校验后解包的 Ubuntu python3-tk 与 tk8.6-blt2.5 包，仅在工程内使用，没有修改系统或 Conda 安装。对应上游版权文件保留在该运行时的 usr/share/doc 目录。换系统后应使用对应系统版本的 Python/Tk，不直接复用这份二进制运行时。

验证：GUI 真实创建、平滑中文字体、加载用户现有结果（3407/4047，84.19%）、进度解释、内置报告打开、字号调整、轨迹分段检查均通过。测试脚本 `tests/gui_smoke.py` 使用本工作站实际结果，运行时须设置 DISPLAY；截图部分使用临时测试显示 :91。
